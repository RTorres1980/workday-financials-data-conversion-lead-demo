# Workday Financials Data Conversion Lead Demo

## 📘 Overview
This project simulates the end-to-end data conversion process for a Workday Financials implementation — including data extraction, transformation, validation, and reporting.  
It’s designed to demonstrate practical expertise in leading a data conversion workstream involving legacy systems such as NetSuite, Concur, and BlackLine.

---

## 🧱 Key Features
- **Data Mapping**: Define mappings between legacy ERP fields and Workday data objects.  
- **Transformation Scripts**: Convert legacy CSV data into Workday-formatted data gathering workbooks.  
- **Validation**: Perform quality checks to ensure completeness, accuracy, and consistency.  
- **Reporting**: Generate automated conversion summary and status logs.

---

## 🧰 Tech Stack
- **Python** (data extraction, transformation, validation)
- **Pandas** for data manipulation
- **Excel / CSV templates** for mapping and workbooks
- **Markdown documentation** for project governance
- **Power BI / Excel** for conversion dashboards (optional)
